# 启动后的终端界面

配置并启动成功后，交互终端自动进入 fullscreen。顶部固定显示版本、监听地址和 Opus / Sonnet / Haiku 模型配置，下方显示 Rust 服务的 send / response 日志。

- `-> … [sent]`：开始发送上游请求。
- `<- … [streaming]`：已收到上游响应头，开始向客户端提供流式响应；不代表响应已经完成。
- `<- … [received]`：非流式响应已读取并转换完成。
- `<- … [completed]`：上游流已结束且通过完整性校验，代理准备发送最终结束事件；不表示客户端已确认收到。
- `<- … [error]`：请求校验、上游 HTTP、响应转换或流式处理失败。显示 request ID、HTTP 状态码（流内错误为 `n/a`）与错误类型；详情按同一 request ID 查询 `error_logs/*.jsonl`。

所有 `/v1/messages` handler 返回的错误都写入错误日志，包括非法 JSON、请求体过大和参数校验失败。流内错误只记错误，不记 `[completed]`；客户端提前断开不会被标为完成。终端不输出上游错误正文。流式完成的 usage 记录带 `requestId`，可与终端记录关联。

这是一层运行日志展示，不展示请求或响应正文，也不新增请求统计。

配色参考 `claude-code-proxy`：深色底、青绿色标题和 LIVE 状态；模型配置为紫色，`[sent]` 为蓝色，`[streaming]` 为青绿色，`[received]` / `[completed]` 为绿色，`[error]` 及运行故障为红色。HISTORY、更新和手动配置提示为黄色，快捷键及普通诊断为灰色。状态文字始终保留，颜色不作为唯一标识；颜色能力和禁用设置沿用 Chalk 的终端检测。

| 操作 | 按键 |
| --- | --- |
| 逐行滚动 | `↑` / `↓` |
| 翻页 | `PageUp` / `PageDown` |
| 最早保留记录 | `Home` |
| 回到最新记录并自动跟随 | `End` |
| 停止代理并恢复终端 | `Ctrl+C` |

浏览历史时显示 `HISTORY`，新记录不会拉回底部；跟随最新记录时显示 `LIVE`。最多保留最近 1000 行，每行最多 4096 字符；超过屏幕宽度的内容截断显示。缩放窗口会重新排版，少于 9 行时提示扩大窗口。

输入或输出重定向、以及 `TERM=dumb` 环境保留普通日志。更新通知显示在日志区域。使用 `--no-claude-settings` 时，面板会显示手动设置 `ANTHROPIC_BASE_URL` 的提示。

退出 fullscreen 后恢复进入前的屏幕；持久化 usage/error JSONL 仍由 Rust 服务负责。
